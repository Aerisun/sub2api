2. 保存为 example.py

example.py
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["SUB2API_API_KEY"],
    base_url="https://aerisun.top/sub2api",
)
reply = client.chat.completions.create(
    model="kimi-k3",
    messages=[{"role": "user", "content": "你好"}],
)
print(reply.choices[0].message.content)

Python 示例

vectors.py · 向量与重排
import json
from urllib.request import Request, urlopen

API_KEY = "sk-REPLACE_WITH_YOUR_API_KEY"
BASE_URL = "https://aerisun.top/sub2api"

def post(endpoint, body):
    request = Request(
        f"{BASE_URL}/{endpoint}",
        data=json.dumps(body).encode("utf-8"),
        headers={"Authorization": f"Bearer {API_KEY}", "Content-Type": "application/json"},
    )
    with urlopen(request) as response:
        return json.load(response)

vectors = post("embeddings", {
    "model": "qwen3-embedding-4b",
    "input": ["杭州西湖", "语义检索"],
})
print(vectors["data"][0]["embedding"])

ranking = post("rerank", {
    "model": "qwen3-reranker-4b",
    "query": "杭州的景点",
    "documents": ["北京故宫", "杭州西湖", "上海外滩"],
    "top_n": 1,
})
print(ranking["results"])

补充介绍

缓存

缓存用量按上游返回；大于 0 表示命中，字段缺失表示上游未报告。同一会话保留完整历史及稳定的系统提示、工具定义。

接口缓存 Token 字段
Chat Completionsusage.prompt_tokens_details.cached_tokens
Responsesusage.input_tokens_details.cached_tokens
Messagesusage.cache_read_input_tokens（读取）
usage.cache_creation_input_tokens（写入）

Embedding / Rerank 的结果缓存查看 Cache-Status 响应头：hit 命中，fwd=miss 未命中，collapsed 合并相同在途请求，fwd=bypass 跳过缓存。结果复用仍按完整输入 Token 计费。

流式

请求加 "stream": true。Chat Completions 如需用量，同时加 "stream_options": {"include_usage": true}。

思考增量：Chat Completions 读取 delta.reasoning_content，Messages 读取 thinking_delta，Responses 读取 response.reasoning_summary_text.delta。仅显示上游实际返回的内容。

流式用量：Responses 读取 response.completed 中的 response.usage；Messages 合并 message_start.message.usage 与 message_delta.usage。

内部工具

聊天可按需调用联网搜索和生图。Claude / Gemini 图片直接随消息发送，无需识图工具。
