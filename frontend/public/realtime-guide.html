GPT 实时语音

一个 WebSocket 会话可以连续收发音频。推荐从低延迟的 gpt-realtime-2.1-mini 开始。

连接地址为 wss://aerisun.top/sub2api/v1/realtime?model=gpt-realtime-2.1-mini。握手使用 Authorization: Bearer <本站 API 密钥>。模型在连接时选定。

  1. 连接后等待 session.created。输入和输出均为 PCM16、单声道、24 kHz。
  2. 实时采集时，用 input_audio_buffer.append 按 20–100 毫秒发送 Base64 PCM。说完发送 input_audio_buffer.commit，再发送 response.create。本站使用手动提交模式，每次会话同时生成一轮。
  3. 边接收边播放 response.output_audio.delta；字幕来自 response.output_audio_transcript.delta。等 response.done 后在同一连接开始下一轮。会话最长约 10 分钟。

安装 websockets 后即可用下面的示例测试。把一段 24 kHz 单声道 PCM16 WAV 保存为 input.wav，在运行环境中设置 SUB2API_API_KEY。

import asyncio, base64, json, os, wave
from websockets.asyncio.client import connect

async def main():
    with wave.open("input.wav", "rb") as src:
        assert (src.getframerate(), src.getnchannels(), src.getsampwidth()) == (24000, 1, 2)
        pcm = src.readframes(min(src.getnframes(), 30 * 24000))
    url = "wss://aerisun.top/sub2api/v1/realtime?model=gpt-realtime-2.1-mini"
    headers = {"Authorization": "Bearer " + os.environ["SUB2API_API_KEY"]}
    async with connect(url, additional_headers=headers, open_timeout=25) as ws:
        async def send(event):
            await ws.send(json.dumps(event))
        ready = json.loads(await asyncio.wait_for(ws.recv(), 35))
        if ready["type"] != "session.created":
            raise RuntimeError(ready)
        for i in range(0, len(pcm), 4800):
            await send({"type": "input_audio_buffer.append",
                        "audio": base64.b64encode(pcm[i:i+4800]).decode()})
            if i + 4800 < len(pcm):
                await asyncio.sleep(0.1)
        await send({"type": "input_audio_buffer.commit"})
        await send({"type": "response.create",
                    "response": {"output_modalities": ["audio"]}})
        with wave.open("reply.wav", "wb") as out:
            out.setparams((1, 2, 24000, 0, "NONE", "not compressed"))
            while True:
                event = json.loads(await asyncio.wait_for(ws.recv(), 30))
                if event["type"] == "response.output_audio.delta":
                    out.writeframes(base64.b64decode(event["delta"]))
                elif event["type"] == "response.done":
                    if event["response"]["status"] != "completed":
                        raise RuntimeError(event["response"]["status"])
                    print(event["response"]["usage"])
                    break
                elif event["type"] == "error":
                    raise RuntimeError(event["error"])

asyncio.run(main())
