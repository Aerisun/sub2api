# 密钥池调度与检查点约定

调度锁只保护配额、并发占位、会话绑定和恢复探测状态。请求路径中的 JSON
编码、文件读写、TLS 客户端初始化、HTTP 和 systemd 探测均在相应调度锁外执行。

## 分配与提交

1. 在条件变量锁内检查配额并占位，复制独立状态快照。
2. 单独的本地写入线程编码快照，并原子替换运行目录中的检查点。连续更新可以
   合并，但最终快照必须包含已分配请求的全部滚动计数。
3. 调用者通过 `Condition.wait_for` 等待自己的提交，期间释放完整的可重入锁。
   仅在提交成功后才向上游发送请求；本地写入失败或超过两秒则拒绝分配。
4. 独立的持久化线程每 250 毫秒合并复制到原私有状态文件。它不得持有调度锁，
   也不得持有检查点锁执行磁盘 I/O。
5. 请求释放和密钥扩容通知等待者。配额到期使用准确的超时唤醒，避免固定间隔轮询。

恢复探测的 `probe` 标志及工作负载并发必须在等待提交前占位；失败时一起回滚。
新增密钥在提交前标记为 `pending`，不能被分配。扩容串行锁只保护扩容控制请求，
不保护普通模型请求。并发、RPM、调用者思考强度和原始请求内容不因此改变。

## 状态与重启

生产启动入口默认启用 `/run/user/<uid>/sub2api-pool-state/` 本地检查点。
显式的 `runtime_state_path` 可以指定同类私有运行目录；不能指向持久化文件本身。
运行目录权限为 0700，检查点和独占所有者锁文件为 0600。
同一路径只允许一个进程持有写入所有权；重复启动立即失败。

本地原子检查点在普通进程崩溃或服务重启后继续保留完整计数和会话绑定。
首次创建和旧格式迁移在开始接收请求前同步保存恢复标记。
若宿主机重启导致运行文件丢失，从持久化文件恢复时保守冷却完整的 60 秒，
该冷却也先写回本地文件，防止再次重启绕过窗口。
状态仅包含不可逆会话指纹、密钥编号/摘要及调度计数，不包含对话、结果或密钥原文。

`/health` 的 `checkpoint` 提供本地/持久化写入失败数、待提交数、最长本地提交耗时、
持久化积压时间和写入线程存活状态。持久化故障不阻塞其他请求；本地提交故障
不会放行未记录的上游请求。关闭时先完成本地提交，再排空持久化写入。

## 其他公共路径

NVIDIA 线路标记由后台线程读取；新的 TLS Transport 也在请求锁外创建。
短锁仅切换 Transport 和维护引用计数。旧响应读完后关闭旧连接，不重放已输出请求。

CPU 模型控制器的 HTTP/systemd 健康检查不持有控制锁。发布检查结果时，重新核对
控制命令版本、工作进程状态、活动请求和完成计数；繁忙工作进程及未知/超时的
探测不会被误判为故障。较新的维护命令不能被较早返回的探测覆盖。

海外代理绑定保留。本机密钥池地址经已绑定代理的回环 DIRECT 规则到达本机；
真正的 NVIDIA 域名请求仍由池中的已验证海外代理转发。

## 验证与依据

```bash
python3 -m unittest qiniu_pool.checkpoint_test qiniu_pool.tests qiniu_pool.transport_test nvidia_pool.tests nvidia_pool.egress_transport_tests
PYTHONPATH=/data/wenbo/services/cpu-inference python3 -m unittest test_elastic_workers
```

故障测试覆盖慢磁盘、本地提交阻塞、写入失败、进程硬退出、所有者互斥、完整配额恢复、
恢复探测单占位、密钥扩容期间继续调度，以及过期健康探测与维护命令竞态。
64 并发基准使用真实存储与合成调度请求，不调用上游模型，也不伪造磁盘延迟。
模型自身延迟需要另看公网生成记录，不能用调度基准推断。

采用的约定参考 [Python 条件变量](https://docs.python.org/3.10/library/threading.html#condition-objects)、
[SQLite 后台检查点的性能取舍](https://www.sqlite.org/wal.html#performance_considerations)及
[Go 阻塞与互斥诊断](https://go.dev/doc/diagnostics#profiling)。这里使用原子 JSON 检查点，
未引入 SQLite，也没有把 SQLite WAL 放在网络文件系统上。

2026-10-22 的测量、故障回归、真实 API/网页验收和部署记录位于
`output/model-latency-20261022/`。
